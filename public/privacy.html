Política de Privacidad - Codex Personal Assistant

Última actualización: 1 de mayo de 2026

1. Qué es Codex Personal Assistant

Codex Personal Assistant es un asistente personal conectado a WhatsApp que puede recibir mensajes del usuario y generar respuestas para ayudar con consultas, organización y tareas generales.

2. Datos que puede recibir la aplicación

Para operar el servicio, la aplicación puede procesar información enviada o provista mediante WhatsApp y Meta, incluyendo:

  • Número de teléfono de WhatsApp.
  • Contenido del mensaje de texto enviado por el usuario.
  • Audios enviados por el usuario, cuando corresponda.
  • Fecha y hora del mensaje.
  • Identificadores técnicos del mensaje.
  • Estados de entrega o lectura cuando WhatsApp o Meta los provean.

3. Uso de los datos

Los datos se utilizan únicamente para finalidades relacionadas con el servicio:

  • Operar Codex Personal Assistant.
  • Responder mensajes y consultas enviadas por el usuario.
  • Mejorar el flujo técnico del servicio.
  • Registrar eventos técnicos para diagnóstico y mantenimiento.

4. Venta y publicidad

No vendemos datos personales. Tampoco compartimos datos personales con terceros para fines de publicidad.

5. Infraestructura de terceros

Para prestar el servicio puede utilizarse infraestructura de terceros necesaria para su operación, por ejemplo Meta/WhatsApp, servicios de hosting, túneles, herramientas de procesamiento o servicios técnicos equivalentes. Estos proveedores se usan para ejecutar, alojar, transmitir o procesar la información necesaria para el funcionamiento del asistente.

6. Eliminación de datos

El usuario puede solicitar la eliminación de sus datos escribiendo a charfrank123@gmail.com. La solicitud será revisada y se eliminarán los datos asociados cuando corresponda.

7. Actualizaciones de esta política

Esta Política de Privacidad puede actualizarse para reflejar cambios técnicos, legales u operativos del servicio. La versión vigente se publicará en esta página.
